# מייטאון · מרכז בקרה

כלי ניתוח לקבוצת מיי טאון (TASE 2449). אתר סטטי, בלי שרת, בלי חשבונות משתמש.
ארבע לשוניות, ארבעה־עשר מסכים, כל הנתונים מהגילוי הציבורי במאיה.

---

## מה בפנים

```
index.html                    האפליקציה · 4 לשוניות × 14 מסכים
data/app/*.json               כל הנתונים · אין מספרים קשיחים בקוד
data/source-text.txt          מלוא הטקסט מ-6 דיווחים פומביים · מקור האימות
data/xbrl/*.xbrl              דוחות גולמיים ממגנא
scripts/parse-xbrl.mjs        פרסור דוחות + ולידציה     ← נבדק על 4 דוחות אמיתיים
scripts/fetch.mjs             שליפת נתוני שוק           ← טרם נבדק מול רשת חיה
data/financials.json          פלט הפרסור
control-room-v1.html          הדשבורד הקודם · נשמר, מוזן מ-financials.json
.github/workflows/update.yml  cron יומי
SPEC.md · CONTENTSPEC.md      האפיון הפונקציונלי והתוכני
```

## הרצה

```bash
node scripts/parse-xbrl.mjs      # אופציונלי · מרענן את financials.json
python3 -m http.server 8000
```

ואז `http://localhost:8000`

**חובה שרת.** פתיחת `index.html` ישירות מהדיסק תיכשל — הדפדפן חוסם `fetch`
על פרוטוקול `file://`. הדף לא ייפול בשקט: הוא יציג מסך שגיאה עם ההוראה הזו.

## עדכון נתונים · רבעון חדש

כל הנתונים יושבים ב-`data/app/`. **הקוד לא משתנה בין רבעונים, רק ה-JSON.**

| קובץ | מה בפנים |
|---|---|
| `meta.json` | מקור ותקופה · יתרות הבסיס · ספי הקובננטים וספי החריגה · מגמת הון והון חוזר · היקף הפעילות |
| `bond.json` | תנאי אג״ח סדרה א׳ · **לוח הסילוקין נגזר מהתנאים, לא מוקלד** |
| `statements.json` | מאזן (40 שורות, 3 תקופות) · רווח והפסד (14 שורות, 5 עמודות) |
| `projects.json` | 8 פרויקטים בביצוע · 7 בתכנון · 13 בהתחדשות עירונית · מסירות |
| `related.json` | מטריצת צדדים קשורים |
| `events.json` | אירועים מהותיים |

לכל קובץ שדה `_note` שמסביר את עצמו, ולכל מספר חריג שדה `_source` עם ההפניה למקור.

## מבחן החריגה

סף כפול, לפי SPEC סעיף 3.2 — ניתן לעריכה ב-`meta.json` תחת `exceptionThresholds`:

| סף | ערך | נימוק |
|---|---|---|
| אחוז | 10% | ברירת מחדל |
| סכום | 375 | 1% מההון העצמי, לא מהמאזן |

שני הספים נחצו → אדום · אחד מהם → ענבר · **מעבר סימן → אדום תמיד**, בלי תלות בספים.

ההון העצמי נבחר כעוגן ולא המאזן: במינוף 7.47 עיגון למאזן היה מייצר סף של 3,184
ואז כמעט שום דבר לא היה נדלק.

## המעקב

לחיצה על ״למעקב״ בכל מסך מוסיפה פריט לאוסף שב־**ביקורת · מעקב**.
לכל פריט: מסך מקור, סכום, חומרה, סטטוס (פתוח ← הוסבר ← נסגר ← הועבר) ושדה הסבר חופשי.

**אחסון:** `localStorage` של הדפדפן, בתוך `try/catch`. אחסון חסום אינו מפיל את הדף —
הוא מוריד את המעקב לזיכרון בלבד ומדליק חיווי אדום במסך.

**גיבוי והעברה בין מכשירים:** ייצוא JSON (ייבוא חוזר) וייצוא CSV לנייר עבודה.
האחסון המקומי פרטי לדפדפן — הוא לא עובר בין מכשירים ולא נשמר בגיט.

## מה חסר

1. **חיבור האפליקציה לפייפליין ה-XBRL.** כרגע `data/app/*.json` מוזן ידנית
   ו-`data/financials.json` מוזן אוטומטית — הם לא מדברים. ה-XBRL של מגנא נותן
   ~50 סעיפים מצרפיים בלבד, ולכן הוא יכול להזין את יתרות הבסיס ואת סכומי הביניים,
   אך לא את 40 שורות המאזן ולא את נתוני הפרויקטים.
2. **XBRL של Q1, Q2 ו-Q4 של 2025** — פותחים את מבחן 3 לכל שורה, את גזירת Q4,
   ואת בדיקת הסכימה השנתית.
3. **יתרות מפורטות ל-31.3.2026** — פותחות את המבחן השוטף בלשונית האנליטי.
4. **תשואת האג״ח בשוק** — דורשת נתוני מסחר. התנאים, לוח הסילוקין והבטוחות כבר בפנים.
