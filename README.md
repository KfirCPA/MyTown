## הרצה

```bash
node scripts/parse-xbrl.mjs      # אופציונלי · מרענן את financials.json
python3 -m http.server 8000
```

ואז `http://localhost:8000`

**חובה שרת.** פתיחת `index.html` ישירות מהדיסק תיכשל — הדפדפן חוסם `fetch`
על פרוטוקול `file://`. הדף לא ייפול בשקט: הוא יציג מסך שגיאה עם ההוראה הזו.

## האוטומציה

רץ יומית ב-GitHub Actions, בארבעה שלבים. כל שלב מדווח, ואף שלב לא בולע כישלון.

```
1. שליפה      מאיה · מגנא · ציטוט האג״ח · כתבות        → sources.json
2. פרסור      XBRL עם ולידציה חשבונאית                  → financials.json
3. התאמה      כל מספר ידני מול ה-XBRL, ואז גזירה        → reconcile.json + meta.json
4. שמירה      commit לרפו · היסטוריה מלאה בגיט
```

### מה נשלף בפועל

ארבע ריצות ב-Actions הכריעו מה אפשר לשלוף ומה לא:

| מקור | מצב | מה מגיע |
|---|---|---|
| **ציטוט אג״ח · ביזפורטל** | ✅ עובד | תשואה ברוטו ונטו, מח״מ, מרווח ממשלתי, ערך מתואם, טווח לפדיון |
| **כתבות · Google News RSS** | ✅ עובד | 16 פריטים בריצה האחרונה |
| דיווחי מאיה | ⛔ חסום ב-CI | WAF מחזיר *security violation* עם support ID |
| דיווחי מגנא | ⛔ חסום ב-CI | 403 עם דף חסימה זהה לכל נתיב |

מאיה ומגנא חוסמות כתובות IP של מרכזי נתונים. **זו לא תקלה שאפשר לתקן בכותרות.**
האדפטרים נשארים כי הם עובדים מהרצה מקומית מכתובת ביתית:

```bash
node scripts/fetch-sources.mjs        # מהמחשב שלך · מאיה ומגנא יענו
git add data/ && git commit && git push
```

הם מסומנים `blockedOnCI`, ולכן מסך הבקרה מבחין בין ״נפל״ לבין ״חסום מראש״.
אדפטר שנראה שבור בלי סיבה הוא בדיוק מה שגורם להתעלם מהמסך.

**השליפה מנסה כמה נקודות קצה לכל מקור** ובודקת שהמבנה שחזר באמת נראה
כמו הנתון המבוקש לפני שהוא נכנס. היומן המלא נשמר ומוצג בלשונית **בקרה**.
שלושה כללים שלא נשברים: נתון שלא עבר ולידציית מבנה לא נכנס · כישלון מסמן
מיושן ולא מוחק · כישלון של מקור אחד לא מפיל את השאר.

**ציטוט נכנס רק כשהוא טרי.** נתון מסחר ישן גרוע מנתון חסר, כי הוא נראה טרי.
ציטוט שסומן כמיושן אינו נכנס, והשדה חוזר להצגת ״דורש נתוני מסחר״.

**ההתאמה היא השער.** היא משווה את היתרות, את סכומי הביניים, את סכימת שורות הפירוט
ואת שורות הרווח וההפסד מול ה-XBRL — ומאמתת שהמצטבר החצי-שנתי באמת שווה ל-Q1 ועוד Q2.
סטייה עוצרת את הכתיבה ומפילה את הריצה. נכון להיום: **32 בדיקות, אפס סטיות.**

בדיקה ידנית:

```bash
node scripts/fetch-sources.mjs --selftest   # הפרסרים מול פיקסטורות, בלי רשת
node scripts/build-app-data.mjs             # התאמה בלבד, לא כותב
node scripts/build-app-data.mjs --write     # כותב רק אם אין סטייה
```

זה הגבול, והוא לא ניתן להזזה: התיוג של הרשות מכיל כ-50 סעיפים מצרפיים.

| נגזר אוטומטית | נשאר ידני |
|---|---|
| סך נכסים · הון מאוחד · הון לבעלים · זכויות מיעוט · הון חוזר | 40 שורות המאזן המפורטות |
| מגמת ההון ומגמת ההון החוזר · כל הנקודות | 14 שורות הרווח וההפסד המפורטות |

השורות הידניות אינן בלתי-מבוקרות: ההתאמה מוודאת שהן מסתכמות לסכומי הביניים
שה-XBRL כן מכיל. טעות הקלדה בשורה בודדת נתפסת ומפילה את הריצה.

## מבחן החריגה

סף כפול, לפי SPEC סעיף 3.2 — ניתן לעריכה ב-`meta.json` תחת `exceptionThresholds`:

| סף | ערך | נימוק |
|---|---|---|
| אחוז | 10% | ברירת מחדל |
| סכום | 375 | 1% מההון העצמי, לא מהמאזן |

שני הספים נחצו → אדום · אחד מהם → ענבר · **מעבר סימן → אדום תמיד**, בלי תלות בספים.

ההון העצמי נבחר כעוגן ולא המאזן: במינוף 7.47 עיגון למאזן היה מייצר סף של 3,184
ואז כמעט שום דבר לא היה נדלק.

## המעקב

לחיצה על ״למעקב״ בכל מסך מוסיפה פריט לאוסף שב־**ביקורת · מעקב**.
לכל פריט: מסך מקור, סכום, חומרה, סטטוס (פתוח ← הוסבר ← נסגר ← הועבר) ושדה הסבר חופשי.

**אחסון:** `localStorage` של הדפדפן, בתוך `try/catch`. אחסון חסום אינו מפיל את הדף —
הוא מוריד את המעקב לזיכרון בלבד ומדליק חיווי אדום במסך.

**גיבוי והעברה בין מכשירים:** ייצוא JSON (ייבוא חוזר) וייצוא CSV לנייר עבודה.
האחסון המקומי פרטי לדפדפן — הוא לא עובר בין מכשירים ולא נשמר בגיט.

## מה חסר

1. **XBRL של Q1, Q2 ו-Q4 של 2025** — פותחים את מבחן 3 לכל שורה, את גזירת Q4,
   ואת בדיקת הסכימה השנתית. כרגע ההתאמה מסמנת 9 בדיקות כ״לא ישימות״ בדיוק בגללם.

   חסר רק הפירוט לשורה.
3. **הסכמי המימון הבנקאי** — להגדרת ״המאזן״ באמות המידה. ראה למטה.
4. **שטר הנאמנות המלא** — ליישוב הסתירה בסף יחס ההון.

## אמות מידה מול הבנקים · שאלה פתוחה

הסכמי המימון דורשים (ס׳ 11.3 לתיאור עסקי התאגיד):

| אמת מידה | רצפת סכום | רצפת יחס למאזן |
|---|---|---|
| הון עצמי המיוחס לבעלי המניות | 5,000 | 15% |
| הון עצמי מוחשי, לרבות הלוואות בעלים | 12,000 | 30% |

הקריאה המילולית של ״שיעורו מהמאזן״ **נכשלת בכל התאריכים** — 11.8% ל-30.6.2026,
13.8% ל-31.12.2025 — אבל החברה מצהירה במפורש שב-31.12.2025 היא **אינה בהפרה**.
המסקנה אינה שיש הפרה, אלא ש״המאזן״ בהסכמי המימון אינו המאזן החשבונאי.
מול המאזן המתואם, אמת המידה הראשונה עומדת (19.3%) והשנייה עדיין לא.

**האפליקציה מציגה את שתי הקריאות ואינה קובעת הפרה.** ההגדרה חסומה עד לקבלת
הסכמי המימון, והפריט פתוח במעקב.

הפרה, אם תהיה, אינה עילה להעמדה לפירעון מיידי — היא מקנה למממן שיקול דעת.
זו הבחנה שמבדילה אותן מקובננטי האג״ח.
